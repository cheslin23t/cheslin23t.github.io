Build log · 2021 to now

The work
between the highlights.

The featured projects are the strongest finished stories. This is the wider path: selected tools, prototypes, and experiments that expanded what I could build next.

  1. 2021 Early project

    Bots · Event-driven JavaScript

    Spade

    An early Discord bot organized around command files and event handlers, with per-server prefixes and music controls. It was my entry point into asynchronous, event-driven software.

    View the early code ↗
  2. 2022 Archived project

    Discord automation · Node.js / MongoDB

    Cyberblade Bot

    A learning project that took my earlier bot work into slash commands, modular command loading, interactive polls, and database-backed server settings. The repository is preserved as a 2022 snapshot, not a production-ready bot.

    View the archived source ↗
  3. 2022 Troop software

    Operations · Flask / Replit DB

    BSA2

    Initially built for my Boy Scout troop’s website, this Flask app served as the troop’s primary trip RSVP flow and gave organizers a simple view of who was and was not attending. It is preserved as early operational software.

    View the archived project ↗
  4. 2022 Experiment

    Real-time software · Node.js

    spaceChat

    A learning project for accounts, direct messages, and live Socket.IO events backed by MongoDB. It is earlier exploratory work, not a production chat system.

    Explore the experiment ↗
  5. 2023–24 Prototype

    Backend · Accounts · Data

    ProveIt

    A Flask and MySQL prototype with blueprint-based features, account routes, sessions, and a database-backed dashboard—an early step toward more structured backend applications.

    See the prototype ↗
  6. 2024–26 Featured system

    Business software · Flask / MySQL

    Printed

    Customer order intake, admin review, and tracked print records for a 3D-printing business. This turned the patterns from earlier prototypes into software for a real workflow.

    See the featured project ↑
  7. Late 2025–26 Featured tool

    Developer tools · APIs

    JB-X

    A Python CLI that made Jailbreak item APIs faster to explore, with a decorator-based command registry, aliases, contextual help, and interactive selection for ambiguous searches.

    See the featured project ↑
  8. 2026 Reusable starter

    Backend architecture · Flask / MySQL

    Modular Flask Template

    A starter organized into feature modules, with account routes, shared database helpers, environment configuration, and setup guidance for the next Flask project.

    Browse the starter ↗
  9. Now Featured product

    iOS · On-device machine learning

    BadAvo

    An iOS product that brings image recognition into a focused everyday experience: assessing avocado ripeness with a model that runs on the device.

    See the featured project ↑
