From form fields to a database record.

The customer-facing flow I built, using HTML, Bootstrap, JavaScript, Python, Flask, and MySQL.

  1. HTML + BootstrapCollect the request

    Contact details, a model link or custom-model description, dimensions, budget, and payment preference.

  2. JavaScriptAdapt the form

    Show the relevant fields for an existing Thingiverse model or a custom-made model, and update the required inputs.

  3. Python + FlaskValidate the submission

    The POST /order/submit route checks the expected field types, whole-number budget, and supported payment methods.

  4. MySQLStore structured data

    A parameterized INSERT writes the customer's details and model requirements to the Submissions table.
