JB-X.

A Python command-line interface for Roblox Jailbreak item data.

View source

Purpose

Make repeated item-data queries easier to run and extend than a set of one-off scripts.

Implementation

A decorator registers each command alongside its description, usage, and aliases. Startup discovers command modules; the dispatcher resolves canonical names and aliases through the same registry.

Interaction

The homepage demonstrates command-specific help and alias resolution. The full CLI also handles ambiguous item searches with an interactive selection and maintains prompt history.

Limits

Item data comes from third-party APIs. The browser demonstration uses local command metadata and does not claim current prices or live API access. Trade comparison and duplicate-item queries remain experimental.
