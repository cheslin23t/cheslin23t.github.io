Printed.

A customer order form backed by Python, Flask, and MySQL.

View source

Original project

Purpose

In 2024, my friends and I started a 3D-printing business. I built a website where customers could describe a print and provide the details needed to prepare it.

Customer interface

HTML and Bootstrap structure the storefront and order form. Customers can supply contact information, a budget, payment preference, and either a Thingiverse model ID or a description, reference image, and dimensions for a custom model.

JavaScript

Conditional fields adapt the form to the type of model requested. Choosing a custom model reveals description, image-reference, and size fields; choosing an existing model requests its Thingiverse ID.

Python and Flask

The order route is organized in a Flask blueprint. POST /order/submit checks the expected field types, validates the whole-number budget and supported payment method, and normalizes the model information before storage.

MySQL

A database helper supplies the connection. A parameterized INSERT stores the customer's contact details, budget, payment preference, referral, and model requirements in the Submissions table, followed by a database commit.

Embedded version

The portfolio embeds Printed’s published site directly, using the same HTML, styles, assets, and customer form as the standalone project. Its embed option skips the opening dialog and keeps the original form usable within the frame. The published archive does not send orders or run the Flask/MySQL backend; those remain inspectable in the linked source.
