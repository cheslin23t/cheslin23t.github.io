Printed.

Customer intake and admin review for a 3D-printing business.

View source

Original project

Purpose

In 2024, my friends and I started a 3D-printing business. I built software to connect customer requests with the admin workflow.

Implementation

The Flask application separates customer submissions from accepted print records. The intake captures model details, size, budget, payment method, and contact information. Admin review approves or denies submissions.

Design

The homepage opens with the original storefront artwork. Its Order workflow view shows how submitted details become a print record, using fictional data and local browser state.

Limits

The walkthrough does not submit real orders or connect to a database. It demonstrates the intended source workflow, not current deployment readiness. Editing paid, printed, or delivered status is not demonstrated.
