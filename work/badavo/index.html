BadAvo.

An iOS app for assessing avocado ripeness with an on-device image-recognition model.

View on the App Store

Project website

Purpose

Bring avocado ripeness assessment into a focused mobile experience.

Implementation

The portfolio documents a custom image-recognition model running on the device, with Swift, Core ML, and Vision as the application stack.

Evidence

The published App Store listing and its actual screenshots establish the released product. The interface shown on the homepage comes from those published assets.

Limits

No model-accuracy, latency, dataset-size, or adoption figures are asserted here. The browser presentation shows published screens; it does not run the model.
